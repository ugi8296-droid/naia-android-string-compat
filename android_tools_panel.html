ChatGPT 기기 플러그인

연결한 플러그인에서 이 기기의 현재 프롬프트를 확인하거나 허용한 작업을 요청할 수 있습니다. NAIA 실행부가 켜져 있어야 합니다.

이미지 생성은 연결된 NovelAI 계정을 사용하며 해당 이용 한도와 잔액이 적용됩니다.

전체 화면 조작에는 Settings·입력·생성·파일 버튼도 포함됩니다. AI가 요청받은 작업을 화면에서 수행합니다. 비밀번호·인증 키 값은 화면 공유 시 가립니다. 별도 수정·생성 도구 스위치는 화면 버튼 조작을 제한하지 않습니다.

브라우저에서 연결 페이지 열기

처음 연결할 때는 읽기만 허용합니다. 연결 파일은 다른 사람에게 보내지 마세요.

Comic Maker

만화 구성안을 만드는 PromptServer를 이 기기 안에서 실행합니다. 처음 준비할 때 원작자의 GitHub에서 검증된 실행 파일을 내려받습니다. PC나 Termux는 필요 없습니다.

준비 버튼은 만화를 생성하지 않습니다. 이후 만화 만들기를 실행하면 앱에 연결한 NovelAI 계정으로 이야기·구성안과 이미지를 생성합니다. 무료 여부는 각 요청의 NovelAI 이용 조건을 따릅니다.

준비 후 앱을 다시 열면 실행부도 다시 시작합니다. 이미 실행 중인 외부 서버는 변경하지 않습니다.
