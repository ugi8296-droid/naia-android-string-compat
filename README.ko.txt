NAIA Android 문자열 호환성 패치

목적
Android APK 0.4에서 일부 Arrow 문자열 커널이 없어 발생하는 문자열 처리 오류를 보완하는 확장입니다. 기존 APK와 Python 환경을 사용하며 추가 패키지를 내려받지 않습니다. pandas의 공식 문자열 저장 옵션을 Python으로 설정하고 NAIA의 일부 내부 검색 함수를 보완합니다. 확장 설치·승인 기능은 NAIA가 제공하지만, 내부 검색 함수에 대한 패치는 공식 확장 API 밖에 있는 버전별 호환성 처리입니다.

설치 파일
extension.json, main.py, naia_android_strings.py를 같은 폴더에 함께 두어야 합니다. 저장소로 배포할 경우 이 파일들을 GitHub 저장소 루트에 둡니다. 이 패키지를 만드는 것만으로 GitHub에 게시되지는 않습니다.

휴대폰에서 설치
1. 이 패키지가 게시된 GitHub 저장소 주소를 준비합니다.
2. NAIA 앱의 Settings → Extension을 엽니다.
3. 상단 주소 입력란에 저장소 주소를 붙여 넣고 “GitHub에서 설치”를 누릅니다.
4. 설치된 “NAIA Android 문자열 호환성 패치”의 활성화 스위치를 누릅니다.
5. 코드를 신뢰할 수 있는지 확인한 뒤 “신뢰하고 활성화”를 누릅니다. 확장은 앱과 같은 권한으로 Python 코드를 실행합니다.
6. 기존 시작 오류 상태를 초기화하려면 Android 설정에서 NAIA를 강제 종료한 뒤 다시 엽니다. 데이터 삭제나 재설치는 하지 않습니다.
7. 확장에 오류가 표시되지 않는지 확인하고 Random을 다시 실행합니다.

설치에는 GitHub 접속이 필요합니다. 설치된 호환성 패치 자체는 네트워크나 추가 다운로드 없이 휴대폰 안에서 실행되며, 활성화 상태이면 백엔드를 시작할 때마다 적용됩니다. NAIA의 이미지 생성 등 원래 온라인 기능은 별도입니다.

ZIP 파일을 직접 선택하여 확장을 설치하는 기능은 현재 원본 NAIA에 없습니다. GitHub 게시가 아직 안 되었다면 위 주소 설치 절차는 실행할 수 없습니다. 앱이 확장 폴더에 대한 직접 파일 접근을 제공하는 경우에만 Settings → Extension에 표시된 설치 폴더 아래에 확장 폴더를 복사하는 수동 설치가 가능합니다.

해제·업데이트
해제하려면 Settings → Extension에서 이 확장을 끄고 Android 설정에서 NAIA를 강제 종료한 뒤 다시 엽니다. 웹 화면 새로고침이나 작동 스위치만으로는 이미 적용된 Python 패치가 해제되지 않습니다.
원본 설치기는 같은 확장 ID의 덮어쓰기를 지원하지 않습니다. 업데이트 패키지의 별도 안내를 따르고, 새 ID로 설치할 때에는 기존 패치를 먼저 끈 뒤 백엔드를 완전히 다시 시작합니다.
