# NAIA 저장 폴더 선택 · 0.1.0

기존 NAIA Android 앱에서 저장경로를 직접 입력하는 대신 **폴더 목록을 눌러 선택**하는 확장입니다. 새 앱이나 Termux를 설치하지 않습니다.

## 설치

1. 기존 앱의 **Settings → Extension → GitHub 설치**에 아래 주소를 붙여 넣습니다.

   `https://github.com/ugi8296-droid/naia-android-string-compat/tree/storage-picker`

2. **NAIA 저장 폴더 선택**을 활성화하고 코드 실행을 승인합니다. 확장 기능의 전체 작동 스위치도 켜 주세요.
3. 앱을 완전히 종료한 뒤 다시 엽니다.
4. 저장경로 **톱니바퀴 → 폴더 목록에서 선택**을 누릅니다.
5. 시작 위치와 폴더를 고른 뒤 **이 폴더에 저장**을 누릅니다. 실제 쓰기와 설정 저장이 확인되면 선택창이 닫힙니다.

기존 문자열 호환성 패치와 ChatGPT 연결 확장은 그대로 사용할 수 있습니다. 이 확장은 같은 앱 안에 추가되며 다른 확장을 덮어쓰지 않습니다. 확장을 끄고 앱을 다시 시작하면 원래 화면으로 돌아갑니다.

## 바뀌는 동작

- 앱 이미지 폴더, 현재 저장 폴더, 접근 가능한 내부 공유 저장소를 탐색합니다.
- 상위 폴더로 이동하거나 새 폴더를 만들 수 있습니다. 새 폴더 생성과 저장 위치 적용은 별도 동작입니다.
- 선택할 때 작은 PNG 파일을 잠시 만들고 지워 쓰기 가능 여부를 확인합니다. 실패하면 오류를 표시하고 기존 저장경로를 유지합니다.
- 단순 탐색이나 선택창 취소는 저장경로를 바꾸지 않습니다. 이미 명시적으로 만든 새 폴더는 취소해도 남습니다.
- 날짜별 하위 폴더, 파일명, 분류 등 기존 저장 옵션을 유지합니다. 선택한 폴더 아래에 기존 옵션에 따른 하위 폴더가 생길 수 있습니다.
- 직접 입력란은 **고급: 경로 직접 입력**으로 접었습니다. Android 문서 URI를 파일 경로처럼 잘못 적용하지 않도록 차단합니다.

## Android 저장 권한 범위

**갤럭시 기본 파일 선택창이나 새 저장 권한을 받는 기능은 아닙니다.** 현재 앱에 이미 허용된 파일 경로를 선택합니다. 공유 저장소가 접근 불가로 표시되면 이 확장만으로 새 권한을 받을 수 없습니다. Android 시스템 폴더 선택과 문서 URI 저장은 원본 APK 실행부에 별도 연동이 필요합니다.

앱 이미지 폴더가 앱 전용 공간에 있으면 삼성 내 파일이나 갤러리에서 바로 보이지 않을 수 있습니다. 권한이 없는 공유 폴더를 선택 가능한 것처럼 표시하거나 그곳에 저장됐다고 처리하지 않습니다.

## 검증 범위

NAIA v2.0.48의 원본 Python Headless Web 저장 서비스와 화면을 대상으로 합니다. 예상한 화면 코드와 다르면 적용을 중단합니다. 원본 파일은 수정하지 않습니다.

호스트 환경에서 실제 원본 저장 서비스를 사용해 PNG 내용과 메타데이터 보존, 빠른 저장, 파일명 충돌, 설정 유지, 쓰기 실패, 설정 저장 실패 복원, 경로 제한, 확장 설치·활성화, ChatGPT 연결 확장과의 동시 사용을 검사했습니다. 폴더 선택과 취소의 JavaScript 동작 및 루프백 통신도 검사했습니다.

**실제 Galaxy/Android 기기와 Android WebView에서는 아직 검증하지 않았습니다.** 이 배포물은 기존 앱에 설치하는 확장이고, Android 실행부를 재빌드한 APK가 아닙니다.
