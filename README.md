# NAIA Android 도구 0.2.3

0.2.3: 자동 스크롤·뷰포트 크기 변경도 사용자 입력으로 간주해 클릭 정보를 폐기하던 경로를 수정했습니다. 클릭할 대상의 위치·내용·가림 여부는 실행 시 다시 검사합니다. 화면 명령 연결을 닫힌 설정 대화상자에서 분리했습니다. 메인 화면의 주기적 신호와 화면 복귀 신호로 연결을 재확인합니다. get_state는 실행부 버전·화면 연결 상태를, get_screen은 화면 코드 버전을 반환합니다. 업데이트 후 **수정한 확장 다시 불러오기 → NAIA 화면 새로고침**이 필요합니다. 이전 화면은 이전 연결 주소를 가지고 있으므로 코드 교체만으로 갱신되지 않습니다. 갤럭시 실기기에서의 최종 확인은 아직 필요합니다.

0.2.2: Quick 등 메뉴와 관계없는 화면 갱신이 클릭 정보를 무효화하지 않도록 수정했습니다. 전체/간편 화면 전환 및 표준 탭·펼치기 탐색을 추가했습니다. 설정·인증·생성·파일 변경 차단은 유지합니다. 기존 복구 도구에서 **GitHub 최신 수정본 확인 → 확인한 수정본 적용 → 수정한 확장 다시 불러오기** 후 화면을 새로고침하세요.

NAIA v2.0.48 Android 앱용 확장입니다. APK 재설치나 Termux가 필요하지 않습니다.

배포 후 설치 주소: https://github.com/ugi8296-droid/naia-android-string-compat/tree/android-tools

처음 설치하는 경우 Settings → Extension → GitHub에서 설치에 주소를 넣고 확장을 활성화한 뒤 작동 스위치(Activate This Script)를 켭니다. 앱을 완전히 종료하고 다시 실행하세요. Settings → Global → **Android 도구 · 플러그인**에 설정이 생깁니다. 기존 문자 호환, ChatGPT 연결, 저장 폴더 선택 확장은 유지합니다.

**0.1.0 또는 0.2.0이 이미 설치된 경우** 같은 주소로 다시 설치하지 마세요. 원본 v2.0.48 설치기는 같은 확장 ID의 덮어쓰기를 거절합니다. 복구 확장 `https://github.com/ugi8296-droid/naia-android-string-compat/tree/android-tools-repair`의 안내를 따르세요. 기존 연결 파일과 설정을 보존합니다. 기존 0.2.0 업데이트 확장에 다시 설치를 요청하지 않아도 됩니다.

0.2.1에서는 확장을 재시도할 때 이전 Python 모듈이 남아 `screen_service` 인자를 거부하던 문제를 수정했습니다. 실행 파일의 실제 내용으로 모듈을 구분하고, 이전 실행부를 종료한 뒤 새 실행부를 연결합니다. 복구 확장은 설치된 GPT 연결·저장 폴더 확장의 알려진 중복 등록·중복 화면 패치 문제도 함께 교정합니다.

## 작가 썸네일

저메모리 모드는 기본으로 켜져 있습니다. 큰 썸네일 JSON 파일 전체를 메모리에 올리지 않고 디스크 색인을 만든 뒤 필요한 작가의 이미지만 읽습니다. 모든 작가, 검색, 페이지, 즐겨찾기를 유지합니다. 처음 접근할 때 목록 준비가 필요하며 완료되면 자동으로 다시 표시합니다. 다운로드한 원본 파일은 바꾸거나 지우지 않습니다.

이미지 캐시는 기본 32MB이며 16/32/64MB를 선택할 수 있습니다. 앱 전체 메모리 한도를 뜻하지 않습니다. 저메모리 스위치를 끄면 기존 로딩 방식으로 돌아갑니다.

## 폴더 열기

Android 파일 앱이 읽을 수 있는 저장 폴더는 파일 앱으로 엽니다. 접근할 수 없는 경우에는 NAIA 안에서 저장된 이미지를 24장씩 읽기 전용으로 보여 줍니다. 확대와 페이지 이동을 지원합니다. 아티스트 폴더는 기존 아티스트 목록으로 안내합니다. 새로운 저장 권한은 요청하지 않습니다.

## ChatGPT 플러그인

개인 연결 페이지: https://naia-tablet-link.ugi8296.chatgpt.site

1. Android 도구 설정의 **연결 페이지 열기**를 누릅니다.
2. 연결 페이지에서 **연결 파일 만들기**로 JSON 파일을 받습니다.
3. NAIA 설정에서 받은 JSON 파일을 가져옵니다.
4. ChatGPT의 개인 플러그인 **NAIA 연결**을 설치·연결합니다.

연결하면 처음에는 상태 읽기만 허용됩니다. 별도 GPT 추론 API 키를 요구하지 않습니다. 이미지 생성은 기존 NovelAI 계정을 사용하며 계정의 이용 조건과 잔액이 적용됩니다.

| 설정 | 허용되는 동작 |
| --- | --- |
| 현재 프롬프트·설정 읽기 | 프롬프트와 일부 생성 옵션·진행 상태 조회 |
| 앱 화면 보기·캡처 | 현재 화면의 텍스트, 입력칸·버튼 목록 및 요청 시 캡처 |
| 메뉴 이동·클릭·스크롤 | 확인된 메뉴·목록·스튜디오 이동. 화면 보기 권한도 필요 |
| 프롬프트·생성 옵션 수정 | 프롬프트, 캐릭터·작가 입력, 지원되는 생성 옵션 변경. 화면 입력에는 보기·조작 권한도 필요 |
| 이미지 생성 요청 | 별도 생성 도구로 1장 요청. 일반 클릭으로 생성 버튼을 누르는 경로는 차단 |

Settings, 로그인, API 키, 계정·플러그인 연결 설정은 항상 차단합니다. 이런 화면이 열려 있으면 화면 캡처·조회 자체를 거부합니다. 파일 다운로드·삭제·외부 링크·임의 JavaScript 실행도 화면 조작에 포함하지 않습니다. 원본에서 동작을 확인한 메뉴만 조작 대상으로 제공하며, 미지원 버튼은 `unsupported_control`로 표시합니다.

`naia_get_screen`으로 화면을 조회하고 반환된 `snapshot_id`, `target`을 `naia_ui_action`에 사용합니다. 허용 동작은 `click`, `fill`, `select`, `scroll`입니다. 화면이 바뀌거나 사용자가 직접 조작하면 다시 조회해야 합니다. 화면에는 앱의 현재 프롬프트와 이미지가 포함될 수 있습니다. 캡처는 요청할 때만 만들며 전송 확인 후 기기에서는 캡처 원본을 보관하지 않습니다. 서버에서 1일이 지난 명령 결과는 이후 기기 통신 때 순차적으로 정리합니다. 기기가 통신하지 않으면 더 오래 보관될 수 있습니다.

지원 작업: 기기 목록, 현재 프롬프트와 일부 생성 설정 조회, 프롬프트 수정, 이미지 1장 생성 요청, 생성 상태, 이 플러그인이 추가한 대기 중 요청 취소. 이미 실행 중인 생성이나 사용자의 다른 대기 작업은 취소하지 않습니다. 다른 작업이 진행 중이거나 대기열이 비어 있지 않으면 새 생성을 시작하지 않습니다.

NAIA 실행부와 인터넷 연결이 켜져 있어야 합니다. 화면 기능은 NAIA 화면도 열려 있어야 하며, 여러 화면이 열리면 먼저 연결한 한 화면에서만 작업합니다. 전달되지 않은 명령은 120초 뒤 만료되고 화면 실행 응답은 15초 안에 받아야 합니다. 접수는 완료를 뜻하지 않습니다. 종료된 앱을 실행하는 기능은 아닙니다.

연결 파일은 다른 사람에게 보내지 마세요. 앱의 연결 해제는 로컬 자격 증명을 지우고, 연결 페이지의 기기 해제는 서버에서도 해당 기기를 차단합니다. 일반 확장 설정과 진단 로그에 비밀 키를 넣지 않습니다.

히스토리 보존 방식은 변경하지 않습니다. 화면 캡처는 Web UI를 렌더링한 이미지이며 Android 시스템 화면 캡처가 아닙니다. 실제 갤럭시에서의 최종 동작은 설치 후 확인해야 합니다.
