# NAIA 저장 폴더 선택 · 0.1.1

기존 NAIA Android 앱에서 저장경로를 직접 입력하는 대신 **폴더 목록을 눌러 선택**하는 확장입니다. 새 앱이나 Termux를 설치하지 않습니다.

## 기존 설치 복구 · 업데이트

이미 저장 폴더 선택을 설치했다면 같은 확장을 다시 설치하지 않습니다. 기존 앱의 **Settings → Extension → GitHub에서 설치**에 다음 복구 도구 주소를 입력합니다.

`https://github.com/ugi8296-droid/naia-android-string-compat/tree/android-tools-repair`

1. **NAIA Android 복구·업데이트**를 활성화하고 코드 실행을 승인합니다.
2. 복구 도구에서 **내장 0.2.1 수정본 적용**을 누릅니다. Android 도구 0.2.1과 함께 기존 저장 폴더 선택 0.1.0을 확인해 0.1.1로 수정합니다.
3. **수정한 확장 다시 불러오기**를 누르고 NAIA 화면을 새로고침합니다. 실행부 재시작이 필요하다고 표시되면 앱을 완전히 종료한 뒤 다시 엽니다.
4. 저장경로 **톱니바퀴 → 폴더 목록에서 선택**을 엽니다.

앱 삭제·재설치나 데이터 초기화는 필요 없습니다. 확장 ID `naia_storage_picker_v1`, 기존 저장 위치와 설정을 유지합니다. 설치된 파일이 확인한 원본과 다르면 해당 항목을 건너뛰고 결과에 표시합니다. 이후에는 같은 복구 도구의 **GitHub 최신 수정본 확인 → 확인한 수정본 적용**으로 업데이트합니다.

## 0.1.1 수정 사항

- 확장을 다시 불러올 때 이전 폴더 창 실행부를 정리합니다.
- 이미 수정한 화면에 다시 적용할 때 나던 “저장 폴더 화면 버전이 달라” 오류를 고칩니다.
- 업데이트한 Python 소스를 다시 읽고, 종료된 폴더 창의 주소가 남지 않도록 합니다.
- 다른 확장의 화면 수정과 기존 저장 옵션을 유지합니다.

## 처음 설치하는 경우

저장 폴더 선택을 한 번도 설치하지 않았다면 `https://github.com/ugi8296-droid/naia-android-string-compat/tree/storage-picker`를 사용합니다. 활성화 후 저장경로 **톱니바퀴 → 폴더 목록에서 선택**을 누릅니다. 시작 위치와 폴더를 고른 뒤 **이 폴더에 저장**을 누르면 실제 쓰기와 설정 저장을 확인해 적용합니다.

기존 문자열 호환성 패치와 ChatGPT 연결 확장은 그대로 사용할 수 있습니다. 확장을 끄고 앱을 다시 시작하면 원래 화면으로 돌아갑니다.

## 바뀌는 동작

- 앱 이미지 폴더, 현재 저장 폴더, 접근 가능한 내부 공유 저장소를 탐색합니다.
- 상위 폴더로 이동하거나 새 폴더를 만들 수 있습니다. 새 폴더 생성과 저장 위치 적용은 별도 동작입니다.
- 선택할 때 작은 PNG 파일을 잠시 만들고 지워 쓰기 가능 여부를 확인합니다. 실패하면 오류를 표시하고 기존 저장경로를 유지합니다.
- 단순 탐색이나 선택창 취소는 저장경로를 바꾸지 않습니다. 이미 명시적으로 만든 새 폴더는 취소해도 남습니다.
- 날짜별 하위 폴더, 파일명, 분류 등 기존 저장 옵션을 유지합니다. 선택한 폴더 아래에 기존 옵션에 따른 하위 폴더가 생길 수 있습니다.
- 직접 입력란은 **고급: 경로 직접 입력**으로 접었습니다. Android 문서 URI를 파일 경로처럼 잘못 적용하지 않도록 차단합니다.

## Android 저장 권한 범위

**갤럭시 기본 파일 선택창이나 새 저장 권한을 받는 기능은 아닙니다.** 현재 앱에 이미 허용된 파일 경로를 선택합니다. 공유 저장소가 접근 불가로 표시되면 이 확장만으로 새 권한을 받을 수 없습니다. Android 시스템 폴더 선택과 문서 URI 저장은 원본 APK 실행부에 별도 연동이 필요합니다.

앱 이미지 폴더가 앱 전용 공간에 있으면 삼성 내 파일이나 갤러리에서 바로 보이지 않을 수 있습니다. 권한이 없는 공유 폴더를 선택 가능한 것처럼 표시하거나 그곳에 저장됐다고 처리하지 않습니다.

## 검증 범위

NAIA v2.0.48의 원본 Python Headless Web 저장 서비스와 화면을 대상으로 합니다. 예상한 화면 코드와 다르면 적용을 중단합니다. 원본 파일은 수정하지 않습니다.

호스트 환경에서 실제 원본 저장 서비스를 사용해 PNG 내용과 메타데이터 보존, 빠른 저장, 파일명 충돌, 설정 유지, 쓰기 실패, 설정 저장 실패 복원, 경로 제한, 확장 설치·활성화, ChatGPT 연결 확장과의 동시 사용을 검사했습니다. 폴더 선택과 취소의 JavaScript 동작 및 루프백 통신도 검사했습니다.

0.1.1에서는 원본 확장 관리자로 기존 재시도 오류를 재현하고, ChatGPT 연결·Android 도구와 함께 반복해서 불러올 때의 화면 합성과 설정 보존을 오프라인으로 검증했습니다. 이전 폴더 창 주소 교체, 소스 캐시 갱신, 수정한 화면의 JavaScript 문법도 검사했습니다.

**실제 Galaxy/Android 기기와 Android WebView에서는 아직 검증하지 않았습니다.** 이 배포물은 기존 앱에 설치하는 확장이고, Android 실행부를 재빌드한 APK가 아닙니다.
