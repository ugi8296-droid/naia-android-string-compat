# NAIA Android 문자열 호환성 패치

NAIA Android 0.4에서 Arrow 문자열 함수 누락으로 검색 상태 조회와 Random이 중단되는 문제를 보완하는 확장입니다.

## 설치

1. 기존 NAIA 앱에서 **Settings → Extension**을 엽니다.
2. 주소 입력란에 다음 주소를 붙여 넣습니다.

   https://github.com/ugi8296-droid/naia-android-string-compat/tree/main

3. **GitHub에서 설치**를 누릅니다.
4. **NAIA Android 문자열 호환성 패치**를 활성화하고 **신뢰하고 활성화**를 누릅니다.
5. Android 설정에서 NAIA를 **강제 종료**한 뒤 다시 엽니다.
6. Random을 실행해 프롬프트가 바뀌는지 확인합니다.

확장은 앱과 같은 권한으로 Python 코드를 실행합니다. 데이터 삭제나 재설치는 필요하지 않습니다. ZIP 파일을 직접 가져오는 설치 방식은 원본 앱에서 지원하지 않습니다.

## 적용 내용

- pandas의 공식 문자열 저장 옵션을 Python으로 설정합니다.
- NAIA의 태그 검색, 등급 처리, 심화 검색에서 필요한 문자열 처리를 보완합니다.
- 기존 Arrow 데이터와 Parquet 저장 형식을 유지합니다.
- 추가 패키지 설치나 계정 키가 필요하지 않습니다.
- 설치된 패치는 기기 안에서 실행되며, 활성화 상태에서는 백엔드 시작 때마다 적용됩니다.

## 검증 범위

Python 3.12.14 / pandas 3.0.3 / PyArrow 24.0.0 환경에서 누락 함수를 모사한 17개 검사를 통과했습니다. 실제 데이터로 연속 Random, 검색 조건, 저장 데이터 재로딩, 확장 승인과 재시작 유지를 검사했습니다.

**실제 Galaxy 기기에서의 실행은 아직 확인하지 않았습니다.** 원본 Android 래퍼 대신 공개 NAIA v2.0.48 코드를 기준으로 검증했습니다. 계정 연결이나 유료 이미지 생성은 실행하지 않았습니다. 저장 경로 화면 문제와 일부 null 태그에서 나타나는 원본 Prompt Engineering 경고는 별도 확인이 필요합니다.

이 저장소는 배포에 필요한 패치 코드, 라이선스, 설치 설명을 포함합니다.

## 해제

앱의 Extension 화면에서 확장을 끄고 Android 설정에서 NAIA를 강제 종료한 뒤 다시 엽니다. 화면 새로고침만으로는 이미 적용된 패치가 해제되지 않습니다.
