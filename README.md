# NAIA Android 도구 0.2.7

AI가 NAIA 웹 화면을 확인하고 조작한 뒤 변경된 화면을 확인하도록 연결합니다. 기본 화면 조회와 조작 결과에 화면 이미지를 포함합니다. 연속 영상 스트림이나 Android 시스템 전체 원격 조작은 아닙니다.

0.2.5는 Settings·로그인·입력·생성·파일 버튼의 기능별 허용 목록을 제거합니다. 실제 표시된 HTML 컨트롤을 탐색하고, Prompt/Params/Negative 및 상단 탭을 큰 썸네일 목록보다 먼저 읽습니다. 레이아웃상 표시되는 fixed 패널이 조상 요소의 사각형 때문에 누락되던 판정을 수정합니다. 비밀번호·인증 키 값은 공유할 때 가립니다.

캡처 중 배경 상태·썸네일 갱신만으로 결과 전체를 버리지 않습니다. 캡처가 실패하면 `capture_error`를 반환합니다. 특히 클릭이 실행된 뒤 이미지가 실패한 경우에도 조작을 실패로 바꾸거나 자동 재실행하지 않습니다. 잘못된 연결·소비된 화면 ID·변경되거나 가려진 대상 검사는 유지합니다.

## 0.2.7 사진·폴더 불러오기

히스토리 아래 **사진·폴더**를 누르면 앱 안에서 사진 보관함이 열립니다. **사진 불러오기**에서 현재 저장폴더·앱 이미지폴더·접근 가능한 공유저장소를 눌러 탐색하고, 한 장이나 여러 장을 선택하거나 **이 폴더 전체**를 가져옵니다. 하위 폴더 포함은 선택할 수 있습니다. 경로를 직접 입력하거나 외부 파일 앱을 실행할 필요가 없습니다.

사진은 원본을 수정하지 않고 앱 전용 보관함에 순차 복사합니다. 같은 내용의 사진은 중복 저장하지 않습니다. PNG의 원본 메타데이터를 보존하고, 보관함 목록은 앱 재실행 후에도 유지합니다. 가져오기를 취소하면 완료한 사진은 남습니다. 복사본은 기기의 저장공간을 사용합니다.

목록은 페이지로 나누고 작은 썸네일만 불러옵니다. 두 장을 선택해 비교할 수 있고, 상세 화면에서 필요할 때만 **히스토리에 추가**하여 기존 기능으로 이어집니다. 폴더 전체를 기존 메모리 히스토리에 몰아 넣지 않습니다. 기존 히스토리에 추가한 사진은 원래 NAIA의 자동저장 설정을 따릅니다.

현재 앱 실행부가 읽을 수 있는 폴더를 탐색합니다. Android에서 접근이 차단된 폴더의 권한을 새로 받는 네이티브 SAF 기능은 포함하지 않습니다. 지원 형식은 PNG·JPEG·WebP이며, 파일당64MiB·4천만 화소를 초과하거나 읽을 수 없는 파일은 건너뛰고 결과에 표시합니다.

## 0.2.6 Comic Maker 수정

PromptServer 연결 실패 후 작업 스레드가 끝나도 `NAI 작업 중`으로 남던 EXten 패널을 종료 시 다시 갱신합니다. 실제 진행 중인 요청·생성·대기 계획은 유지하며, 중지 버튼을 눌러도 아직 HTTP 요청이 끝나지 않았다면 중복 실행을 허용하지 않습니다. EXten 원본 파일은 덮어쓰지 않습니다.

Comic Maker가 필요로 하는 별도 PromptServer를 앱 실행환경 안에서 준비할 수 있습니다. **Settings → Extension → Android 도구 0.2.6 → Comic Maker 실행부 준비** 또는 **Settings → Global → Android 도구 · 플러그인 → Comic Maker**를 사용합니다. 준비 자체는 생성 요청을 하지 않습니다. 이후 사용자가 만화 만들기를 실행하면 연결된 NovelAI 계정으로 이야기·구성안·이미지를 생성하며 무료 이용을 보장하지 않습니다.

원작자 `okawaritsuika/PromptServer`의 고정 커밋을 기기에서 직접 내려받고 파일 해시를 확인합니다. 원본 서버 소스를 이 업데이트에 재배포하지 않습니다. 서버 파일과 DB는 앱 전용 폴더에 보존됩니다. 원본의 Windows 전용 인증 저장 대신 NAIA에 연결한 NAI 토큰을 요청 시 메모리에서 읽습니다. 별도 토큰 파일이나 환경변수에 복사하지 않습니다.

이미 켜진 다른 서버를 종료하거나 덮어쓰지 않습니다. 설치된 실행부는 다음 앱 실행 때 다시 시작하며, `실행부 끄기`로 자동 시작을 해제할 수 있습니다. GitHub 다운로드나 Android 의존성에 문제가 생기면 상태에 표시합니다. 실제 기기 준비 결과와 만화 생성 성공은 별도로 확인해야 합니다.

## 연결과 권한

연결 페이지: https://naia-tablet-link.ugi8296.chatgpt.site

| 기기 옵션 | 범위 |
| --- | --- |
| 현재 프롬프트·설정 읽기 | 별도 상태 조회 도구 |
| 앱 화면 보기·캡처 | Settings를 포함한 현재 웹 화면 읽기 |
| 전체 화면 조작 | 보이는 메뉴·입력·Settings·생성·파일 버튼 클릭, 입력, 선택, 스크롤 |
| 별도 프롬프트 수정 도구 | 화면을 거치지 않는 직접 프롬프트 변경 도구 |
| 별도 이미지 생성 도구 | 화면을 거치지 않는 직접 이미지 생성 도구 |

전체 화면 조작에는 화면 보기 권한이 필요합니다. 별도 수정·생성 스위치는 화면 버튼 조작을 제한하지 않습니다. 기존 연결 정보와 스위치 값은 업데이트 시 보존됩니다. AI는 사용자가 요청한 작업을 수행하며 생성·삭제·계정 변경을 검증용으로 실행하지 않습니다.

`naia_get_screen`은 기본 이미지와 조작 대상 목록을 반환합니다. `capture:false`는 텍스트만 요청합니다. 명령 접수는 실행 성공이 아니므로 `naia_get_command`로 실제 완료 결과를 확인합니다. `snapshot_id`와 `target`으로 `naia_ui_action`을 실행하고 결과의 새 화면을 확인합니다. 이미지 수신 실패는 이미지를 본 것으로 간주하지 않습니다.

최근 화면 정보는 최대 4개·120초 유지되며 조작 한 번 뒤 이전 정보는 모두 소비됩니다. 다른 브라우저 화면으로 연결이 바뀌면 `screen_session_changed`로 거부합니다. 여러 창에서 동시에 조작하지 않습니다.

## 범위

이 연결은 앱 내 NAIA 웹 UI를 조작합니다. Android 시스템 파일 선택창, 다른 앱, 다른 출처 iframe 내부, 화면 밖 항목, 임의 코드 실행은 제공하지 않습니다. 입력·메뉴가 iframe 안에 있는 경우 별도 연동이 필요합니다. 화면 밖 항목은 스크롤 후 다시 조회합니다. 드래그·키보드 단축키 전송은 현재 도구에 없습니다.

작가 썸네일 저메모리 모드와 16/32/64MB 이미지 캐시, 저장 폴더 열기 기능은 유지합니다. 기존 저장 경로·OAuth·페어링을 유지합니다. 사진 보관함은 기존 생성 히스토리와 별도로 보존합니다.

실제 갤럭시에서 새 버전의 이미지 수신과 메뉴 이동 확인은 적용 후 수행해야 합니다. 테스트 통과를 기기 실행 성공으로 간주하지 않습니다.
